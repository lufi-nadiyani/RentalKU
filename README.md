RENTALKU - APLIKASI SEWA MOBIL

Aplikasi web modern untuk penyewaan mobil dengan sistem autentikasi, manajemen mobil, dan pemesanan terintegrasi.

---

FITUR

- Login/Register - Dua peran: Penyewa & Admin
- Katalog Mobil - Filter & pencarian mobil
- Pemesanan - Pilih tanggal, jam, upload dokumen (KTP/SIM)
- Pembayaran - Virtual Account (BCA, Mandiri, BRI, BNI) & E-Wallet (GoPay, OVO, DANA)
- Admin Panel - Dashboard, CRUD mobil, manajemen pesanan, laporan keuangan
- Laporan Keuangan - Filter tanggal & cetak laporan

---

CARA MENJALANKAN

1. Clone repository
   git clone https://github.com/lufi-nadiyani/RentalKU.git

2. Masuk ke direktori
   cd rentalku

3. Install dependencies
   npm install

4. Jalankan development server
   npm run dev
